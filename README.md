# dewordler

Yet another wordle solver website. It's a bit rough around the edges but you can try it at https://lemonlime4.github.io/dewordler

## How to use

Letter keys, backspace, and arrow keys work mostly as
expected. Ctrl + Backspace deletes the whole word. To input
colors, you can:

- type minus, plus, and spacebar to change the letter's
  color to yellow, green and blank;
- type numbers 1-5 to cycle through the color at that
  letter;
- click letters to cycle through colors.

Finally, words with missing letters will be ignored during search.

No, there is no mobile support yet. Sorry.
