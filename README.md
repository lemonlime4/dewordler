# dewordler

Yet another wordle solver website. It's a bit rough around the edges but you can try it at https://lemonlime4.github.io/dewordler

## Input

To input letter colors, you have two choices.

- Minus, plus, and space set the letter to yellow, green, and blank respectively.
- Numbers 1-5 to cycle through the colors at the corresponding letter.

Delete key to delete a whole word; arrow keys, backspace and enter mostly as usual.
